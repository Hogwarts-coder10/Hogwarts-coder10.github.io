Why I Built GlassBoxML?

I wanted to understand what really happens inside model.fit(): how gradient descent updates weights, how a decision tree picks its splits. So I rebuilt the algorithms on plain NumPy. The math turned out to be the easy part; API design, validation, numerical stability, testing and packaging were the real work. “The best way to understand an abstraction is to remove it.”
